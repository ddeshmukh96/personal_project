To check status: sudo service mysql status

To start the server: sudo service mysql start

To stop the server: sudo service mysql stop

All above commands are used in Linux Terminal not the MySQL terminal

| Step | Command                            | Purpose              |
| ---- | ---------------------------------- | -------------------- |
| 1    | `sudo apt update`                  | Update package lists |
| 2    | `sudo apt install mysql-server -y` | Install MySQL        |
| 3    | `sudo service status mysql`      | Check MySQL service  |
| 4    | `sudo mysql_secure_installation`   | Secure installation  |
| 5    | `sudo mysql` or `mysql -u root -p` | Log in to MySQL      |
| 6    | `mysql --version`                  | Verify version       |


PROBLEM STATEMENT : To create 

USE SchoolDB;

CREATE TABLE CLASS (
    ClassID INT PRIMARY KEY AUTO_INCREMENT,
    ClassName VARCHAR(50) NOT NULL,
    Teacher VARCHAR(50)
);

CREATE TABLE STUDENT (
    StudentID INT PRIMARY KEY AUTO_INCREMENT,
    Name VARCHAR(50) NOT NULL,
    Age INT,
    ClassID INT,
    AdmissionDate DATE,
    FOREIGN KEY (ClassID) REFERENCES CLASS(ClassID)
);
