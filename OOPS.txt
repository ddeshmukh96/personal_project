    total = 0

        total += i
    return total

13. Member Function: direct_reporting
def direct_reporting(self, emp_list):
    count = 0
    M_ID = self.Emp_ID
    for i in emp_list:
        if i.Manager_ID == M_ID:
            count += 1
    return count

What this does:

self refers to the manager object

Compares other employees’ Manager_ID

Counts direct subordinates

print(Emp4.direct_reporting(emp_list))

Meaning:

Emp4 has 3 employees directly reporting to them

Class and Object Attributes — Easy Explanation
1. What is a Class?

A class is a blueprint.
It defines what data and what behavior an object will have.
A class itself does not store individual student data.

Example:

class Student:
    college_name = "PCCOE, Pune"

2. Class Attribute (Common for All Objects)
What is it?

A class attribute:

Is written inside the class

Is not written using self

Is shared by all objects

college_name = "PCCOE, Pune"

Meaning:

All students belong to the same college, so this value is common.

Access:

Student.college_name
s1.college_name
s2.college_name


All give the same value.

3. Object / Instance Attributes (Unique for Each Object)
What are they?

Object attributes:

Are written using self

Store object-specific data

Have separate memory for each object

self.name_of_student = name
self.roll_no_of_student = roll_no
self.marks_scored = marks

Meaning:

Each student has:

Different name

Different roll number

Different marks

4. Objects Created from the Class
s1 = Student("Dhananjay", 9, 93.6)
s2 = Student("Pawan", 11, 96)
s3 = Student("Sarvesh", 29, 90)

Object	Name	Roll No	Marks
s1	Dhananjay	9	93.6
s2	Pawan	11	96
s3	Sarvesh	29	90

Each object has its own data, but they all share the same college.

5. Important Rule About Constructors

In Python:

Only one __init__ constructor exists

The last one written overrides earlier ones

So this constructor is used:

def __init__(self, name, roll_no, marks):


The default constructor is ignored.

6. How Data is Accessed
Object attributes:
s1.marks_scored
s2.name_of_student
s3.roll_no_of_student

Class attribute:
Student.college_name
s2.college_name

7. One-Line Difference (Very Important)
Type	Written Using	Memory	Example
Class attribute	Class name	Shared	college_name
Object attribute	self	Separate per object	name, roll_no, marks
8. Final Easy Summary

Class attribute → common data for all objects

Object attribute → personal data for each object

Objects share the class attribute

Objects have their own instance attributes

This is how Python models real-world relationships correctly.


Default Constructor:

A constructor with only self and no parameters is
commonly called a default constructor.

It:

Takes no external arguments

Performs default initialization
